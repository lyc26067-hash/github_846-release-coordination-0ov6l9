# 2026-W32 Release Plan

Release window label: 2026-W32
Release cut-off: 2026-08-14

## Definition of Done
Every pull request opened for this release must be reviewed and merged before the release cut-off. Pull requests that do not meet the definition of done are blocked and must be left open for manual follow-up.

## Scope
Only the following feature keys are part of this release:
- release-notes (docs/release-notes)
- pricing-page (web/pricing.html)
- security-hardening (config/security.json)

A pull request is ready to merge only when its head branch feature key is listed above, its title contains that exact feature key, and it is still open.
